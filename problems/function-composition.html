Double Increasing Function

Let $f, g : \mathbb{N} \to \mathbb{N}$ be strictly increasing, with

$$f(f(x)) = g(x).$$

Suppose $g(1) = k$. We want $k$ to be small enough that, given only the value $k$, infinitely many values of $f$ (including $f(1)$) are forced — i.e. uniquely determined regardless of which valid $f, g$ we pick.

Find this $k$.

Solution

Write $f(1) = a$, so $f(a) = g(1) = k$. Strict monotonicity forces $a \geq 2$, and $f(a) = k \geq a + 1$ (since $f$ is strictly increasing on $\mathbb{N}$).

For $k = 1, 2$ no valid $a$ exists. For $k = 3$, the only choice is $a = 2$, so $f(1) = 2$ and $f(2) = 3$ are both forced. From there $f(3) = g(2)$, and pinning down $g$ as the linear extension $g(x) = ax + (3 - a)$ propagates the chain $f(S_n) = T_n$, $f(T_n) = S_{n+1}$ with $S_n, T_n$ growing without bound, determining $f$ on every natural number.

For $k = 4$, both $a = 2$ and $a = 3$ are consistent, so $f(1)$ is not forced. So the smallest $k$ that pins things down is $k = 3$.

Answer: $3$
