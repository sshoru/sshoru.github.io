Adding and Subtracting

Define a sequence of non-negative integers $\{S_n\}$ by $S_1 = 1$ and, for $n \geq 2$,

$$S_n = \begin{cases} S_{n-1} + n & \text{if } S_{n-1} < n \\ S_{n-1} - n & \text{if } S_{n-1} \geq n \end{cases}$$

So you keep adding $n$ until the running total is at least $n$, then start subtracting. The first few values are $S_1 = 1$, $S_2 = 3$, $S_3 = 0$, and so on.

Let $C_k$ be the (increasing) sequence of indices where $S_n$ hits zero, i.e. $S_{C_k} = 0$. What is $C_7$?

Solution

Suppose $S_a = 0$ for some index $a$. Walking the recurrence forward, the sequence alternates between large and small values, and the next zero appears at index $3a + 3$. So the gaps form a recurrence $C_{k+1} = 3 C_k + 3$ with $C_1 = 3$.

Solving the recurrence gives $C_k = \dfrac{3^{k+1} - 3}{2}$, so

$$C_7 = \frac{3^{8} - 3}{2} = \frac{6561 - 3}{2} = 3279.$$

Answer: $3279$
