Tan Limit

Define

$$t(n) = \int_{0}^{\pi/4} \tan^{2n}(x)\, dx.$$

It turns out $t(5)$ can be written as $\dfrac{a}{b} - \dfrac{\pi}{4}$ for coprime positive integers $a, b$. Find $b - a$.

Solution

Split off $\tan^{2}(x) = \sec^{2}(x) - 1$:

$$t(n) = \int_{0}^{\pi/4} \sec^{2}(x)\tan^{2(n-1)}(x)\, dx - t(n-1).$$

The first integral evaluates via $u = \tan x$ to $\dfrac{1}{2n - 1}$, so we get the recurrence $t(n) = \dfrac{1}{2n-1} - t(n-1)$ with $t(1) = 1 - \tfrac{\pi}{4}$. Telescoping yields

$$t(5) = 1 - \tfrac{1}{3} + \tfrac{1}{5} - \tfrac{1}{7} + \tfrac{1}{9} - \tfrac{\pi}{4} = \tfrac{263}{315} - \tfrac{\pi}{4}.$$

Since $\gcd(263, 315) = 1$, we have $a = 263$ and $b = 315$, giving $b - a = 52$.

Answer: $52$
